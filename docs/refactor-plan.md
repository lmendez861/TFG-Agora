# Plan historico de refactorizacion

Este documento queda archivado como evidencia del proceso inicial de cambio de enfoque del proyecto Agora hacia la gestion de empresas colaboradoras.

No representa tareas pendientes ni el estado actual de la entrega. El estado final se documenta en:

- `docs/memoria-final.md`
- `docs/cumplimiento-entrega-tfg.md`
- `docs/entrega-final-checklist.md`
- `docs/presentacion-defensa-final.pptx`

Resumen historico: el proyecto partia de una base Agora previa y se reoriento hacia un dominio academico de FP Dual, separando backend Symfony, portal interno, portal externo, documentacion publica y monitor privado.
